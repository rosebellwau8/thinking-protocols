# Thinking Protocols

Thinking Protocols is an Artifact-driven library of machine-readable cognitive workflows. Canonical Protocol semantics live in `protocols/<id>/PROTOCOL.md`; registries and runtime packages are generated from those sources.

The v0.1.0 MVP targets four independently authored Protocols: Socratic Questioning, Fact Checking, Steelman Both Sides, and Minimum Experiment. See [the architecture](docs/architecture.md) for the approved design.

Third-party articles and Prompt bodies are not part of this repository. Provenance records attribute inspiration without importing third-party text or licensing terms. The MVP intentionally excludes hosted services, LLM APIs, persistent runtimes, databases, user interfaces, and plugin systems.
